# ux-readability-review

UI の文字と文言（読みやすさ）に関する 8 つの UX 規則をチェックし、対象アプリの文脈に合わせて適用するためのエージェントスキルです。
Claude Code と Codex のどちらでも使えます。

書かれたものを読めて、意味が取れるかを点検します。
読む順番、意味のまとまり、数値の比較、操作の行き先、予定の時点が文字と文言から分かるかを確認し、足りなければ補います。

## 8 つの規則

| 番号 | 規則 | 目的 | 対象となる文字と文言 |
|---|---|---|---|
| 01 | 読む順番をつくる | 見出し、本文、補足の役割が分かり、読む順番を迷わない | 異なる役割の文字が同居する画面 |
| 02 | 強調を一語に絞り意味のまとまりで改行する | 強調点と文の切れ目が分かり、一文を追いやすい | 強調を含む文、見出し、短い説明 |
| 03 | 数値の桁と単位をそろえる | 数値の大小と条件を同じ基準で比べられる | 金額、件数、割合、測定値 |
| 04 | 識別子を意味のある塊で示す | 長い番号を読み違えず、転記や照合をしやすくする | 予約番号、ID、コード |
| 05 | 行間と段落間で読み進める単位を示す | 文と段落の境界が分かり、読み飛ばしや戻りを減らす | 長文、説明文、箇条書き |
| 06 | 文字と背景の明暗差を確保する | 文字が背景に埋もれず、内容を読み取れる | 本文、ラベル、補足文 |
| 07 | リンクとボタンに行き先と結果を書く | 操作の行き先や押した結果を予想できる | リンク、ボタン、行内操作 |
| 08 | 日付と時刻を具体化する | 予定や期限がいつかを一度で把握できる | 予定、期限、予約、履歴 |

各規則の目的、チェック観点、対象外の条件、別の表現で満たす条件、実装上の注意は [skills/ux-readability-review/references/rules.md](skills/ux-readability-review/references/rules.md) にあります。

## このスキルの考え方

守るのは規則とその目的であり、特定の見た目ではありません。
書体名、ポイント数、色コード、固定した改行位置は到達目標にしません。
書体の組み合わせや字間の演出は品格や表情をつくるためのものであり、このスキルでは扱いません。
画面全体のまとまりや情報の優先順位も扱いません。

規則を機械的に当てはめると、短い文に不要な改行を入れたり、比較しない数値に整列を強いたりして、かえって読み取りにくくなります。
そのため、このスキルは次の順で適用の可否を判断します。

1. その問題が実際に起きるか
2. 利用者がその問題で困るか
3. 既存のデザインシステムや文章規約と衝突しないか
4. 実装コストに見合うか

判定は「満たす」「満たさない」「適用しない」「情報不足」の四つに分けます。
チェック観点どおりの表示ができなくても、別の手段で目的を達成できる場合は「適用しない」にせず、その手段の有無で判定します。

読み込み中、空、失敗、権限不足、削除、完了、入力不備など状態の設計は ux-state-review で扱います。
状態に現れる文言の階層や具体性を確認する場合も、状態の有無や遷移、保持、確認の設計とは分けます。

同じ立ち位置の姉妹スキルが三つあります。

- `ux-state-review`：UI の状態（待つ、空、失敗、権限不足、削除、完了、入力不備）
- `ux-structure-review`：画面の構造（まとまりと優先順位）
- `ux-load-review`：記憶、判断、操作の負担

## インストール

使うエージェントのスキルディレクトリに `skills/ux-readability-review` を置きます。
スキルの形式（`SKILL.md` と参照ファイル）は Claude Code と Codex で共通です。

```bash
git clone https://github.com/ktysne/ux-readability-review.git
```

ユーザー共通で使う場合：

```bash
# Claude Code
cp -r ux-readability-review/skills/ux-readability-review ~/.claude/skills/
```

```bash
# Codex
cp -r ux-readability-review/skills/ux-readability-review ~/.codex/skills/
```

特定のプロジェクトだけで使う場合は、そのリポジトリの `.claude/skills/`（Claude Code）または `.codex/skills/`（Codex）にコピーします。

クローンしたリポジトリをそのまま参照したい場合は、コピーの代わりにシンボリックリンクを張っても動作します。

## 使い方

スキルは、見出しと本文の階層、強調と改行、数値と識別子、段落、文字と背景、リンクやボタン、日付や時刻といった文字と文言の設計を含む作業で自動的に使われます。
明示的に使わせる場合は、Claude Code では `/ux-readability-review` と入力し、Codex ではスキル名 `ux-readability-review` を指示に含めます。

例：

- 「管理画面の見出しと説明文の読みやすさをレビューして」
- 「料金一覧で数字を比べやすくし、識別子を転記しやすくしたい」
- 「予約画面のリンク文言と日時の表示を確認して」

レビュー結果は、規則ごとの判定表、優先して直す項目、開発者の判断を要する項目の三つに分けて報告されます。
